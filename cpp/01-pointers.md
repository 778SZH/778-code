# 指针：它到底存的是什么

## 先记住一句话

变量像一个箱子，里面装数据。**每个箱子都有一个门牌号，这个门牌号就是地址。**

指针就是一个普通变量，只是它里面装的是**别人的门牌号**。

```cpp
int a = 10;      // 一个 int 箱子，里面装 10
int* p = &a;     // p 是箱子，里面装 a 的门牌号
```

- `&a` 读作"a 的地址"
- `int*` 读作"指向 int 的指针"（`*` 在这里是类型的一部分）
- `*p` 读作"p 指向的那块东西"

## 两个符号，别搞反

| 写法 | 意思 |
|---|---|
| `&a` | 取地址：把 a 的门牌号拿出来 |
| `*p` | 取内容：顺着 p 里的门牌号，去那个箱子看内容 |

```cpp
int a = 10;
int* p = &a;     // 用 & 拿地址
std::cout << *p; // 用 * 顺着地址取值 -> 10
*p = 20;         // 顺着地址改 -> a 变成 20
std::cout << a;  // 20
```

`*p = 20;` 改的是 `a` 本身，不是改 `p`。这就是指针最大的用处：**通过一个变量，去改另一个变量**。

## 空指针：表示"我还没指向谁"

```cpp
int* p = nullptr;   // 空指针，谁也不指

if (p != nullptr) {   // 用之前先检查
    std::cout << *p;
}
```

`nullptr` 就是数字 0 地址，谁都不该去那儿读。**没初始化的指针最危险**：它里面是随机数，编译器不报错，你一读就崩。所以养成习惯：指针要么指向一个真变量，要么写 `nullptr`。

## 指针和数组

数组的名字，其实就是第一个元素的地址。

```cpp
int arr[3] = {1, 2, 3};
int* p = arr;        // 等于 &arr[0]

p[0]  // 1
p[1]  // 2     和 arr[1] 一样
*p    // 1
*(p+1) // 2    p+1 是"下一个 int"，不是下一个字节
```

`p[1]` 和 `*(p+1)` 是同一件事，写 `p[1]` 更好懂。

## 函数传指针：让函数能改外面的变量

```cpp
void addOne(int* n) {
    *n = *n + 1;      // 顺着地址改
}

int x = 5;
addOne(&x);           // 把地址传进去
// 现在 x 是 6
```

如果写成 `void addOne(int n)`，函数改的是自己的副本，外面看不到变化。

> 更简单的替代：C++ 有"引用"，写成 `void addOne(int& n) { n = n + 1; }`，调用时 `addOne(x)` 不用加 `&`。两种写法能做的事一样，指针在 C 语言里更常用，C++ 里能用引用就用引用。

## 三个常见的错

1. **野指针**：`int* p;` 没赋值就用。里面是随机地址。
2. **空指针没检查**：`int* p = nullptr; *p = 1;` 直接崩。
3. **指针和值搞混**：`p = 5;` 是错的，`*p = 5;` 才是把 5 存到 p 指向的地方。
