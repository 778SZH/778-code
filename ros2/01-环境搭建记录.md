# ROS2 Humble 环境搭建记录

日期：2026-11-06　环境：Windows 11 + WSL2 Ubuntu 22.04.4 LTS

## 一、装在哪（不占 C 盘）

- Ubuntu 的虚拟磁盘整体在 D 盘：`D:\WSL\Ubuntu-22.04\ext4.vhdx`
- ROS2 装在这个 vhdx 里面，所以数据全在 D 盘
- 装完 vhdx 占用约 7.4 GB

## 二、安装步骤

1. 把 Ubuntu 的 apt 源换成 USTC 镜像 —— 国内下载不会卡在几十 KB/s。
2. 加 ROS2 的 apt 源（用清华镜像，比官方源快）：

   ```
   deb [arch=amd64 signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] https://mirrors.tuna.tsinghua.edu.cn/ros2/ubuntu jammy main
   ```

3. 取签名公钥 —— 官方地址 `raw.githubusercontent.com` 在这边连不通，改从 USTC 的 rosdistro 镜像拿：

   ```
   curl -fsSL https://mirrors.ustc.edu.cn/rosdistro/ros.key -o /tmp/ros.key
   sudo cp /tmp/ros.key /usr/share/keyrings/ros-archive-keyring.gpg
   ```

4. 安装桌面版和构建工具 —— 只装 base 版本没有 rviz、demo 这些常用包：

   ```bash
   sudo apt install ros-humble-desktop python3-colcon-common-extensions cmake build-essential
   ```

5. 写进 `~/.bashrc` —— 否则每开一个终端都要手动 `source`：

   ```bash
   echo 'source /opt/ros/humble/setup.bash' >> ~/.bashrc
   ```

## 四、日常怎么用

```bash
wsl -d Ubuntu-22.04                    # Windows 终端里进 Ubuntu
ros2 run turtlesim turtlesim_node      # 终端 1：开小乌龟窗口
ros2 run turtlesim turtle_teleop_key   # 终端 2：方向键控制它走
```

`ros2/verify_env.sh` 可以一键把上面这些检查重跑一遍：

```bash
wsl -d Ubuntu-22.04 -- bash /mnt/d/workspace/cpp-stm32-notes/ros2/verify_env.sh
```
